# اتصال فرم به Google Sheets و Gmail

1. در همان حسابی که به شیت دسترسی ویرایش دارد، یک پروژهٔ جدید در Google Apps Script بسازید و محتوای `Code.gs` را جایگزین کنید.
2. ایمیل مالک از قبل روی `sb.haghshenas81@gmail.com` تنظیم شده است. نام تب مقصد به‌صورت خودکار `Leads` ساخته می‌شود.
3. از Deploy > New deployment، نوع **Web app** را انتخاب کنید؛ دسترسی اجرا را روی حساب خودتان و دسترسی را روی **Anyone** قرار دهید. مجوزهای Sheets و Gmail را تأیید کنید.
4. URL پایان‌یافته با `/exec` در `app.js` تنظیم شده است. اگر deployment جدیدی ساختید، URL جدید را جایگزین کنید.
5. سایت را روی یک دامنهٔ HTTPS منتشر کنید و با یک ایمیل آزمایشی فرم را ارسال کنید.

هر بار که کد Apps Script تغییر می‌کند، یک deployment جدید بسازید یا deployment فعلی را به نسخهٔ جدید به‌روزرسانی کنید. URL `/dev` برای سایت منتشرشده مناسب نیست.
